## ✨ Highlights

- 🌗 **Live Blur Glassmorphism** - Premium UI with GPU-optimized backdrop blur
- 🤖 **AI Chatbot** - Bilingual (Arabic/English) with smart response engine
- 📱 **Mobile-First** - Fully responsive with fluid animations
- 🔐 **Role-Based Access** - Secure Owner, Admin, and Student portals
- 🌐 **Full RTL Support** - Seamless Arabic language integration

## 📂 Project Structure

```
src/
├── app/                 # Next.js App Router & Legal Pages
├── components/          # Features, Layout, and UI Library
├── contexts/            # Global State (Auth, Theme, Lang)
├── hooks/               # Custom React Logic
├── lib/                 # Core utilities & Firebase SDK
├── services/            # Backend Integrations
└── types/               # TypeScript Schema Definitions
```

## 🚀 Quick Start

```bash
# Clone & install
git clone https://github.com/sirahmed8/obour-academic-hub.git
cd obour-academic-hub
npm install

# Run dev server
npm run dev
```
