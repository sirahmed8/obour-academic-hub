# Zencoder Repository Rules

## Handoff Protocol

Read `AGENT_INSTRUCTIONS.md` before making changes. Treat it as the single source of truth for current work, recent changes, known issues, and next steps.

After completing and verifying work, update `AGENT_INSTRUCTIONS.md` with changed files, checks performed, remaining risks, and the next recommended step.
